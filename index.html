Private backup utility

Bridge Daily Backup

Bridge Daily Backup helps its operator keep encrypted, versioned backups of selected application data. It is intended for the operator's own use and is not a public backup service.

What it does

The utility is designed to create a local backup and copy encrypted backup snapshots to the Google Drive account explicitly authorized by its owner. It can read those backups to check their integrity or restore them, and manage their configured retention.

Google Drive access

The requested permission is drive.file. This allows access to files created by this application or specifically authorized for it. The utility does not request access to all files in Drive, Gmail, or Google Photos.

Privacy and security

Backup contents are encrypted on the operator's computer before upload. Only the operator controls the backup recovery passwords. OAuth credentials and recovery passwords are not published on this website.
